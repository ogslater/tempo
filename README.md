# tempo

Este é um projeto desenvolvido no Curso de Programador Front-End do SENAI Maracanã.

A página busca a temperatura ou clima de forma simples e interativa. Tecnologias utilizadas

HTML: Estrutura da página
CSS: Estilização e layout
JavaScript: Lógica de conversão de temperatura e clima

Funcionalidades

informa o clima de todos os lugares do mundo.

Como usar

Abra o arquivo index.html no navegador.
Clique em "Buscar localização".
Escolha o Local, Estado, Pais .
Clique em ok.
